### Description

This project can be approached at any depth - from superficial understanding
   to diving deep into the mathematical foundations. The minimum requirement is
   grasping the general algorithmic concepts.

It is up to the student to go as deeply or superficially as they wish, as long that he can understand the general idea behind an algorithm.

### Features:

- Many explanation alongside modules, bridging theory to application
- Deutsch-Jozsa (ex_5)
- Grover's (ex_6)
- Simon's (ex_7)

### How to run it:

Simply use [jupyter](https://www.youtube.com/watch?v=dQw4w9WgXcQ) in the Browser, or install the VsCode extension.

### Technical outline:

Jupyter was used because qiskit is a multi-step worflow where steps are time-expensive, Jupyter helps around this problem by caching intermediate steps.
